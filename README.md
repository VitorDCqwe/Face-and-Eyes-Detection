# Detecção de Rosto

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Status-Concluído](https://img.shields.io/badge/Status-Concluído-brightgreen?style=for-the-badge&logoColor=white)

Programa para detecção de rostos e olhos pela webcam

---
## 📚 Aprendizados
- Detecção de objetos
- Utilização do Haarcascade

## ⚙️ Funcionalidades
- Mantenha o rosto parado para que o programa identifique seu rosto e seus olhos.

## 🛠️ Stack
Informe as tecnologias, bibliotecas e frameworks utilizados. Exemplos:

- Python
- OpenCV
- Haarcascade

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/VitorDCqwe/Face-and-Eyes-Detection
```

2. Abra o arquivo e execute no teminal.
